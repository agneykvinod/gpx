# GPX Racing

A lightweight browser-based 3D motorcycle racing prototype built with Three.js and hosted from GitHub Pages.

## Current prototype
- 3D GP-style fictional circuit
- Motorcycle placeholder
- Chase camera
- Touch steering
- Throttle and brake controls
- Lean-angle crash logic
- Lap timing
- Device tilt mode where supported
- Lightweight rendering designed for low-end development hardware

## Next milestones
1. Replace placeholder bike with a proper 3D motorcycle
2. Improve motorcycle physics and tyre model
3. Add racing-line visualization
4. Add AI riders
5. Add track environment and pit lane
6. Add sound and effects
7. Add mobile optimization and installable PWA

## Run
Enable GitHub Pages for the repository and open the generated Pages URL over HTTPS. Device motion permissions generally require a secure context.
